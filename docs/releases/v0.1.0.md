# Whistle Dictation v0.1.0

First release of a local Windows tray app that turns a global hotkey into
speech-to-text insertion in your focused textbox.

## Download and run

1. Download **WhistleDictation-v0.1.0-windows-x64.zip** from the release assets.
2. Extract the complete folder to a user-writable location.
3. Run **WhistleDictation.exe** and wait for **Ready**. Python is bundled.
4. Try **Test microphone**, then focus a textbox and press
   **Ctrl+Alt+Shift+Space** to start recording. Press it again to transcribe and insert.

The SHA256 checksum is supplied in **SHA256SUMS.txt**. Keep the entire extracted
folder together, including `_internal/`, `models/`, and `licenses/`.

## Included

- Configurable shortcut, microphone, and spoken language.
- A passive recording indicator and tray controls.
- Local CPU recognition with pinned, verified Cactus Whistle artifacts.
- Personal dictionary, exact replacements, optional cleanup, and long-recording splitting.
- Cancellation, worker recovery, bounded recording, and transcript recovery on delivery errors.
- Professional user, troubleshooting, development, architecture, and acceptance documentation.

Normal recognition needs no network after setup. Automatic insertion preserves
the clipboard and never presses Enter. Audio and transcripts are not saved by
the app; settings and metadata-only logs remain local.

## Validation and release status

This is an early **Windows AMD64** release. The original machine passed 156 tests
and 19 subtests, real synthetic-speech recognition, and packaged startup/runtime
checks. Live microphone and target-application insertion remain desktop acceptance
work. Synthetic-speech accuracy does not establish accuracy on your voice.

Browser/Electron fields can share native handles, elevated applications may block
input, and partial text delivery is possible. Output is a single line. The build
is currently unsigned. See the included acceptance and troubleshooting documents.

Meeting translation and speech-model fine-tuning are outside this version.
